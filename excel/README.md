# Excel workbook

Actual `.xlsx` file with live formulas, a segment selector, Excel Tables, native editable line charts, and a project-specific lab. The workbook preserves prepared monthly source aggregates in Monthly Data; Python owns transaction-level preparation.

Dashboard KPI formulas and charts update when the amber segment selector changes. The scenario or forecast lab has separately labeled controls. Cell formulas are editable and source ranges are bounded to the supplied dataset; adding new months or rows requires extending ranges and chart sources.

Recalculation, selected input changes, output reconciliation, formula-error scans and exported OOXML objects were checked. Microsoft Excel native application was not available for open/save verification. Native PivotTables/slicers and Power Query connections are not precreated; exercises show how to add them yourself.

Open in Microsoft Excel for the intended feature support. Other spreadsheet viewers may render or recalculate charts/formulas differently. See `../docs/hands_on_practice.md` for practice, evidence capture and resume wording.
