# Retail decision brief

Synthetic case study — descriptive findings, not real company performance.

- Net revenue: $1,275,348.26; contribution margin: 31.5%.
- Apparel has the highest return rate (17.1%). Audit sizing, product descriptions, and return reasons before a controlled intervention.
- Trend forecast WAPE: 34.7%; last-month baseline: 7.9%. Select the lower-error approach; this short backtest does not establish long-run accuracy.
- Use the at-risk RFM export for a randomized retention campaign; historical repeat purchase is not evidence that outreach causes retention.

Contribution profit deducts recognized COGS and fulfillment/return costs but excludes acquisition, fixed overhead, and tax. Cohorts start at first observed purchase; customers without a purchase do not enter retention denominators. RFM uses only the observed period.
